# Create: Deep Current

An addon for [Create](https://github.com/Creators-of-Create/Create): marine power plants, electricity carried
through subsea cables, and the pressure of the deep ocean.

> Status: **pre-alpha**. Nothing is playable yet. Test worlds may need to be recreated between versions.

## Targets

| Minecraft | Loader         | Create   | Java |
|-----------|----------------|----------|------|
| 1.20.1    | Forge 47.x     | ≥ 6.0.8  | 17   |
| 1.21.1    | NeoForge 21.1  | ≥ 6.0.10 | 21   |

## Repository layout

```
core/                 Loader-independent logic (pure Java, no Minecraft), unit tested
src/main/             Minecraft code, compiled for every version by Stonecutter
versions/<version>/   Per-version Gradle projects generated by Stonecutter
tools/textures/       Python + Pillow texture generators and the shared palette
art/                  Blockbench (.bbmodel) sources
```

The design document is [DEEP_CURRENT_GDD.md](DEEP_CURRENT_GDD.md) (French).

## Building

Requires JDK 17 and JDK 21 installed (Gradle toolchains pick the right one per version).

```bash
./gradlew build                  # build every version + run core tests
./gradlew :core:test             # run the logic unit tests
./gradlew :1.21.1-neoforge:runClient
./gradlew :1.20.1-forge:runClient
```

Jars land in `versions/<version>/build/libs/`.

### Switching the active version

Stonecutter keeps `src/` written for one *active* version. To edit code for the other version:

```bash
./gradlew "Set active project to 1.20.1-forge"
```

Version-specific code uses Stonecutter comments:

```java
//? if forge {
/*import net.minecraftforge.common.ForgeConfigSpec;*/
//?} else
import net.neoforged.neoforge.common.ModConfigSpec;
```
